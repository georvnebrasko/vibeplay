# VibePlay

VibePlay — desktop-приложение для поиска и запуска Spotify-плейлистов по настроению, атмосфере и любому пользовательскому вайбу.

---

# Описание

Проект представляет собой desktop-приложение для macOS, использующее Spotify API для поиска плейлистов и их воспроизведения.

Приложение позволяет искать музыку по свободным запросам и быстро запускать найденные плейлисты.

Примеры запросов:

- night drive
- villain arc gym
- sad but hopeful
- cyberpunk vibes
- walking alone in Tokyo rain at 3am

# Как запустить

## 1. Клонировать репозиторий

```bash
bash git clone https://github.com/georvnebrasko/vibeplay.git 
```

## 2. Перейти в папку проекта

```bash
bash cd vibeplay 
```

## 3. Установить зависимости

```bash
bash npm install
```

## 4. Запустить web-версию

```bash
bash npm run dev
```

---

## 5. Запустить desktop-версию

```bash
bash npm run electron
``` 

---

## 6. Собрать приложение

```bash
bash npm run dist
```

После сборки приложение появится в папке:

text dist/
