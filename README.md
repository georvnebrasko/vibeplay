# VibePlay

VibePlay — desktop-приложение для Spotify, объединяющее поиск музыки по вайбу и персональный музыкальный архив с системой оценок.

---

# Описание

VibePlay позволяет находить Spotify-плейлисты по любому настроению, сценарию или атмосфере, запускать их напрямую через Spotify и сохранять любимую музыку в личный архив.

Приложение включает две основные системы:

###Vibe Search

Поиск плейлистов по свободным запросам

Найденные плейлисты можно запускать напрямую через Spotify.

Archive

Личная музыкальная библиотека с оценками.

Пользователь может

Все оценки сохраняются локально между запусками приложения.

# Как запустить

## 1. Клонировать репозиторий

```bash
bash git clone https://github.com/georvnebrasko/vibeplay.git 
```

## 2. Перейти в папку проекта

```bash
bash cd vibeplay 
```

## 3. Установить зависимости

```bash
bash npm install
```

## 4. Запустить web-версию

```bash
bash npm run dev
```

---

## 5. Запустить desktop-версию

```bash
bash npm run electron
``` 

---

## 6. Собрать приложение

```bash
bash npm run dist
```

После сборки приложение появится в папке:

text dist/

# Текущий статус

Сейчас реализовано:

- Spotify OAuth авторизация
- автоматическое сохранение входа между запусками
- поиск плейлистов по вайбу
- запуск Spotify-плейлистов

- поиск альбомов, треков и плейлистов

- система пользовательских рейтингов
- поддержка дробных оценок
- независимые рейтинги для альбомов и треков
- просмотр содержимого альбомов
- просмотр содержимого плейлистов

- desktop-приложение на Electron

- кастомный интерфейс в стиле Spotify
- сборка приложения для macOS
